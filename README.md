# Ghadir Al Najjar Skin Studio

موقع تعريفي لأخصائية العناية بالبشرة **غدير النجار**.

## التشغيل محليًا

```sh
npm i
npm run dev
```

## الأوامر

| الأمر | الوصف |
| --- | --- |
| `npm run dev` | تشغيل بيئة التطوير |
| `npm run build` | بناء المشروع للإنتاج |
| `npm run preview` | معاينة البناء |
| `npm start` | تشغيل السيرفر بعد البناء |
| `npm run lint` | فحص الكود |
| `npm test` | تشغيل الاختبارات |
